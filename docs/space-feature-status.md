# Expanded feature status

This supersedes the implementation-status column of the historical [gap audit](alphaspace-gap-audit.md). Feature parity is assessed per workflow, with explicit source limits.

| Area | Implemented | Remaining boundary |
|---|---|---|
| Portfolio | Holdings/News/Insights/Movers/Risk tabs; selected-account news; derived concentration; sortable holdings; shared hide-values preference | Concentration is not a historical risk/volatility model. Recorded value history cannot infer missing transactions or cash flows. |
| Company | Seven fundamentals tabs, comparisons, Auto/K/MM/B, fiscal date ordering, segment period/business/geography choices, richer quote data | Issuer-specific operational KPIs and some consensus fields unavailable. Analyst Track record discloses missing accuracy data; consensus history is labeled separately. |
| Earnings | Rebuilt full-width schedule, selected-day/week filtering, key/all-column views, one linked company analysis panel, company news and economic calendar; history range and quarterly/annual estimate horizons | Missing annual revenue consensus/ranges remain unavailable. Long tables scroll inside their panels. |
| Chart | Six presets/custom styling; 52 studies; editable drawings; replay time/speed/date; searchable annual/quarterly fundamental overlays | Corporate-event history and dividend-adjusted total returns unavailable. Extended-hours filtering only for supported current-session intraday bars. Volume-by-price is explicitly a bar-close estimate. |
| Options | Alpaca indicative snapshots with provider-aware chain/overview/detail, timestamps, partial coverage and explicit Nasdaq fallback; serialized 60s refresh/pause; transaction-flow controls, paging and CSV | Alpaca requires user-supplied credentials and has not been authenticated live. Indicative quotes are modified and derived trades delayed 15 minutes; absent volume/open interest/change stay unavailable. Real transaction data separately requires an eligible Unusual Whales subscription/key. |
| Stock themes | 34 shared research universes; searchable theme browser; Housing/Gambling/Prediction Markets shortcuts; constituent quotes, heatmaps, linked charts and theme-wide news | Editorial universes are not indexes or recommendations. Prediction-market operating exposure is distinguished from indirect investment; private event-contract venues are not listed as stocks. Provider coverage can be partial. |
| Workspace | Icons/ordering/locks, richer header actions, config-only sharing, XLSX/CSV, AI attachment toggles, staged search/commands, goal-specific tours, Blue Steel/cycling, shortcut preference | No Yahoo identity/branding or exact reference backend. |
| Persistence | Validated portable import/export and encrypted manual cross-device sync relay | Hosted relay requires deployment of the new Durable Object binding/migration; no account login or automatic merge. |
| AI | Active selected linked/manual holdings hydration, live attachment context callbacks, financial/options/shared-portfolio tools | Live paid AI service remains unverified without its API key; tools can only return available connected-source data. |
| Notifications | All/price feed, active/triggered filters, sorting, category prefs, opt-in browser permission and visible watchlist news/earnings checks | No background server push or email service. |
| Video | User-selected direct media/approved embeds and publisher-link fallback | No licensed Yahoo Finance TV feed. |
| Automatic refresh | Charts 30s/crypto 15s; quotes/tape 30s; markets/portfolios 60s; news/predictions 2min; research/earnings 5–15min. Visibility/reconnect catch-up, serialized requests, timeout/retry, last-good data and freshness status | These are application polling intervals. Provider delays and closed markets still apply; no stock tick-stream entitlement is configured. |
| Prediction Markets | Dedicated `prediction-board` view with public Kalshi/Polymarket catalogs, complete supplied child-contract expansion, prices/rules/source links, venue pagination, Kalshi combo tickets, loaded-page filtering and rotating 30s refresh | Page counts describe loaded data, not the entire catalog. Price snapshots and Kalshi asks are distinct; volume units differ. Private positions and the complete historical settlement archive are outside this public catalog. |
